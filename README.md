# Proyecto Incendios 🔥

Este proyecto busca analizar y predecir incendios forestales utilizando datos y modelos de inteligencia artificial.  
Incluye notebooks, scripts y documentación que explican el proceso paso a paso.

---

## 📂 Estructura del proyecto
- `Docs/` → Documentación del proyecto (informes, planes, progreso).  
- `data/` → Datos crudos y procesados.  
- `models/` → Modelos entrenados.  
- `visualizations/` → Mapas y gráficas.  
- `Incendios.ipynb` → Notebook principal con el análisis.  
- `paso1_datos_y_modelo.py` → Script para preparar datos y entrenar el modelo.  
- `paso2_rag_knowledge_base.py` → Script para generar la base de conocimiento.  
- `paso3_api_fastapi.py` → API para exponer el modelo.  

---

## 📖 Cómo entender el proyecto
- El **notebook `Incendios.ipynb`** muestra el flujo completo: carga de datos, entrenamiento y visualización.  
- Los **scripts paso1, paso2 y paso3** representan las fases del proyecto:  
  - Preparación de datos y modelo.  
  - Construcción de la base de conocimiento.  
  - Exposición del modelo mediante una API.  
- Los archivos `.json` y `.pkl` guardan resultados, métricas y modelos entrenados.
